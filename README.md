# Rumba G&G Health & Wellness — Netlify Starter

This is a static, mobile-friendly starter site designed for Netlify.

## Files

- `index.html` — page structure/content
- `styles.css` — visual design and responsive layout
- `script.js` — mobile menu and temporary booking notice

## Deploy to Netlify

1. Unzip the project.
2. Drag the `rumba-gandg-site` folder into Netlify's manual deploy area, or connect it to a Git repository.
3. No build command is required.
4. Publish directory is the project root.

## What is intentionally temporary

- Text logo
- Studio/class images
- Class names
- Schedule
- Prices
- Contact information
- Booking/payment provider

## Later booking integration

When a provider is selected, replace the temporary booking buttons with the provider's booking URLs or embed widget.

The current buttons use the CSS class:

`booking-placeholder`

Those can be replaced with normal links such as:

`<a class="btn btn-dark" href="YOUR-BOOKING-LINK">Book</a>`
